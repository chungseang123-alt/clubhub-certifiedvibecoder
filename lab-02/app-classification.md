| 1 | Mobile banking app: ABA | Applicaion Software | Mobile native; web app; cloud service; data-intensive | Clients run on their phones, either IOS or Android, delivered through official app stores. Backend banking logic runs on the bank's secure cloud servers. | **Client-server** : mobile app communicates via secure APIs with the backend servers, which connect to core banking database. **Evidence** : Account balances, transactions, and transfer cannot be processed offline and require a network connection.| **Security** : hacks could allow attackers to steal users' money and private financial information. **Availability** : if the app goes down, people can't pay for things or transfer money in times of emergency. **Reliability** : bugs could cause wrong account balances or charge payment twice. | Seng Sarak |
| 2 | Telegram |Application software |Mobile cross-platform; desktop; web app; cloud service; data-intensive |Phone and desktop clients delivered through app stores or official downloads; browser client delivered through URL; Telegram servers through server-side deployment. Some messages/media are cached on devices.| **Client-server** : apps exchange cloud chats through Telegram servers. **Evidence**: a cloud chat can appear on multiple signed-in devices after synchronization. Secret Chats behave differently though since they are device-specific.|**Security**: compromised accounts could reveal private conversations. **Availability**: an outage could stop time-sensitive group coordination. **Performance**: delayed message delivery could make urgent communication ineffective. |Sok Chungseang |
| 3 | ABS controller in a car | Embedded software | Embedded; real-time; safety-critical; runs inside the car's control unit (ECU); no user interface | Installed in the car's ECU as firmware by the manufacturer; updated only at a service centre. | **Client-server**: not client-server. It is a standalone controller: wheel-speed sensors send data to the ECU, and the ECU controls the brake valves. **Evidence**: it works without internet or a user account, and it starts automatically when the car is turned on. |**Security**: if the firmware or diagnostic port is attacked, the braking behaviour could be changed. **Availability**: if the ABS controller fails, the wheels can lock during hard braking and the driver loses control. **Performance**: it must react within milliseconds, because a delay can make the car skid. | Pheng Sopheak |
