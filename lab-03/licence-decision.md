# Licence decision · ITC Club Hub
Version 1.0 · 2026-11-11 · Lead: Sok Chungseang

| Criterion                               | MIT  | Apache-2.0 | GPL-3.0 |
|-----------------------------------------|------|------------|---------|
| Anyone (incl. companies) may reuse      | Yes | Yes       | Yes    |
| Improvements must be shared back        | No | No       | Yes    |
| Explicit patent grant                   | No | Yes       | Yes    |
| Compatible with GoogleTest (BSD-3)      | Yes | Yes       | Yes    |
| Simple for future student teams         | Yes | Moderate       | Complex    |
| Instructor / institute requirement      | None | None       | None    |

**Decision:** MIT
**Rationale:** We chose MIT License because it is very simple and easy to understand. It allows anyone to share and use our code without any strict rules. It also works great with GoogleTest tools without causing any issues for future student teams and does not force any complex legal rules on our project code. This makes it the best choice for our group project.
